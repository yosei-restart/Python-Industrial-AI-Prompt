# 常见问题 FAQ

## Q1：模板可以直接复制使用吗？

A：可以，完全免费开源，个人/学习/商用均无限制。

## Q2：为什么AI没有执行自检？

A：检查是否完整复制了模板，不要删除自检相关铁律；国产模型可手动要求AI执行自检。

## Q3：可以修改模板中的铁律吗？

A：可以，Fork仓库后可根据自身需求自定义规则。

## Q4：代码无法运行怎么办？

A：1. 检查是否安装对应依赖库 2. 查看AI自检结果 3. 重新粘贴完整模板提问。

## Q5：支持Python哪些版本？

A：默认适配 Python 3.8+ 主流版本，模板会自动做版本兼容校验。

## Q6：可以用于团队开发吗？

A：非常适合，统一AI代码输出规范，减少团队返工和代码审查成本。
