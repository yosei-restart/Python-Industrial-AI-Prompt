# Python 工业级编码规范详解

本模板严格遵循企业级Python开发标准，核心规范解读如下：

## 一、PEP8 编码规范（强制）

1. 缩进使用 4 个空格
2. 变量/函数名：小写+下划线（user_name）
3. 类名：大驼峰（UserInfo）
4. 代码行宽度不超过88字符，避免横向滚动

## 二、异常处理规范

1. 必须捕获：空输入、文件不存在、网络超时
2. 使用精准异常捕获（如 FileNotFoundError），不使用裸 except
3. 异常提示清晰，方便定位问题

## 三、最小修改原则（核心）

1. 仅修改需求相关代码，不改动无关内容
2. 不重构变量名、注释、格式、缩进
3. 保留原有代码风格，不做无意义优化

## 四、安全编码规范

1. SQL 语句参数化，防注入
2. 禁止硬编码密钥、密码、路径等敏感信息
3. subprocess 禁用 shell=True，避免安全风险

## 五、代码可运行性

1. 包含所有 import 导入语句
2. 无省略号、无待实现占位符
3. 附带测试用例，可直接运行验证
