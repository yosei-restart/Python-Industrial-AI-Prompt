# 大模型全平台适配说明

本模板原生适配主流大模型，针对不同平台做以下微调即可最优输出：

## 一、Claude（最优适配）

- 无需任何修改，直接使用完整模板
- 完美支持自检闭环、随机抽查、双层铁律全部能力
- 适合复杂代码、工程化开发、长文本需求

## 二、GPT 系列（GPT-3.5/4o）

- 建议：模板开头追加一句「只输出代码和自检结果，不要多余话术」
- 优势：代码生成速度快，规范度高
- 适配：完整支持所有铁律规则

## 三、国产大模型（通义千问/文心一言/讯飞星火）

### 推荐优化（可选）

1. 精简模板中冗余描述，保留核心铁律
2. 明确要求「严格遵守所有规则，执行完整自检」
3. 避免超长上下文分段，一次性粘贴完整模板

### 通用技巧

- 需求简洁明确，减少口语化描述
- 代码相关需求，优先指定「Python+PEP8规范」
