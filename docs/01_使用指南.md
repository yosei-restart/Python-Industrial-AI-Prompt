# 使用指南

本文档详细说明 Python 工业级编程 AI 提示词模板的使用方法、占位符替换规则、自检机制解读。

## 一、快速使用步骤

1. 打开根目录 `Python-Industrial-Prompt.md` 核心模板文件
2. 替换模板底部的【用户核心问题】和【现有代码（可选）】
3. 全选复制完整模板，粘贴到任意大模型（Claude/GPT/通义/文心）
4. 等待AI输出**可直接运行、符合工业级规范**的Python代码

## 二、占位符替换规则

### 【用户核心问题】

必填项，清晰描述你的需求：

- 代码从零实现
- 代码优化/精简
- Bug 修复/问题排查
- 版本兼容/老旧代码改造
  示例：请帮我写一个带异常处理的JSON文件读写工具

### 【现有代码（可选）】

选填项，仅在需要修改/优化现有代码时粘贴

- 修复Bug：粘贴报错代码
- 代码优化：粘贴待优化代码
- 无现有代码：留空即可

## 三、自检规则解读

AI 输出后会自动执行【规则自检】：

1. **关键项**：强制检查代码规范、可运行性、最小改动等核心规则
2. **抽查项**：随机校验铁律执行情况，杜绝违规输出
3. 若自检显示「违反」，可直接要求AI修正，无需重复说明规则

## 四、注意事项

1. 需求描述越清晰，AI输出越精准
2. 不要删除模板中的任何铁律，否则会失去管控效果
3. 国产大模型建议完整粘贴模板，不要精简内容
